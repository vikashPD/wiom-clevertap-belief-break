How to connect live tracking data

  1. Open sheets.new in Chrome
  2. Click Extensions > Apps Script
  3. Delete default code, paste the tracking-backend.gs code
  4. Click Deploy > New deployment > Web app
  5. Set access to Anyone, click Deploy
  6. Copy the URL and paste it in the input above
